# Student Performance Analysis 📊
Data Analytics project using Python (Pandas + Matplotlib)

## 📌 Project Overview
This project analyzes student performance data using Python. It explores marks distribution, identifies top performers, gender wise performace and visualizes data insights using graphs.

---

## 🛠️ Tools & Technologies Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

---

## 📂 Dataset
The dataset contains student scores in subjects like math, reading, and writing.

---

## 📊 Features / Analysis Performed
- Data loading and exploration using Pandas
- Statistical summary of dataset
- Identification of top-performing students
- Visualization using histograms

---

## 📈 Key Insights
- Distribution of student scores
- Average performance analysis
- Top scorers identification

---

## 📸 Project Screenshots
Screenshots of code execution, output, and graphs are included in the repository.

---

## 🚀 How to Run
1. Open Jupyter Notebook
2. Run `Student_Performance_Analysis.ipynb`
3. Ensure dataset CSV is in same folder
